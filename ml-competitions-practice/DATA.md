# Data files

Removed from this folder's history to keep the repository small and to avoid redistributing third-party material:

- `Competition/HackerEarth A Fine Windy Day/dataset/` - train.csv, test.csv, sample_submission.csv (available from the HackerEarth competition page)
- `Practice/Visualization/dataset/` - multiple_choice_responses.csv from the Kaggle Machine Learning & Data Science Survey
- `Job Preparation/aiNeuron/` - 30 course PDFs from aiNeuron (copyrighted course material)
- `Higher Studies/` - one book PDF (copyrighted)

Notebooks that read these files expect them at the paths above.
