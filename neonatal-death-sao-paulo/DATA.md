# Data files

Two files were removed from this folder's history to keep the repository small:

- `spneodeath.csv` (73 MB) - raw Sao Paulo neonatal records used by the notebooks
- `spneodeath_clean (1).csv` (30 MB) - cleaned version produced during preprocessing

Place them back in this folder before running the notebooks. The source of the raw records is described in the
IJPHS paper (https://doi.org/10.11591/ijphs.v13i1.22577).
